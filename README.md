# AIM Intelligence

Website for AIM Intelligence, built with Next.js (App Router) and TypeScript, deployed on Vercel.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this GitHub repository in Vercel (Add New → Project → Import `aim-intelligence`).
Vercel detects Next.js automatically; every push to the production branch deploys.
