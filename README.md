# AIM Intelligence

A blank page: warm charcoal background (`#141413`) with a static film-grain texture.
Next.js 16 + Tailwind CSS v4, deployed on Vercel from GitHub.

```bash
npm install
npm run dev
```

- Base color and grain strength: CSS variables at the top of `app/globals.css`.
- Grain texture: `public/textures/grain.webp`, a 320px grayscale noise tile shown at 160px.
